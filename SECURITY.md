# Security policy

## Supported version

Security fixes target the current `main` branch and the deployed GitHub Pages site. Historical revisions are not maintained as separate releases.

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/katagun/ai-systems-atlas/security/advisories/new). Do not open a public issue for a suspected vulnerability.

Include the affected file or workflow, reproduction steps, impact, and any suggested mitigation. Avoid including unrelated personal data, credentials, or destructive proof-of-concept activity. We aim to acknowledge a complete report within five business days and will coordinate disclosure after triage and remediation.

Catalog corrections, stale links, and evidence-quality concerns are not security vulnerabilities; use a regular issue or pull request for those.
