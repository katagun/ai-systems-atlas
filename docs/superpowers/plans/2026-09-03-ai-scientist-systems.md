# AI Scientist Systems Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Record the Atlas's position that autonomous scientific-discovery systems route to existing roles, and publish the one product that clears the inclusion gate.

**Architecture:** No vocabulary changes. A new ADR declines a vertical role on four grounds and states the condition for revisiting; three documents carry the prose; one record joins `directory/projects.json` under an existing role; two products go to `BACKLOG.md`'s Watching section because neither is waiting on work in this repository.

**Tech Stack:** Python 3.12 via `uv`, `unittest`, static JSON under `directory/`, generated mirrors under `web/`.

**Spec:** [`docs/superpowers/specs/2026-09-03-ai-scientist-systems-design.md`](../specs/2026-09-03-ai-scientist-systems-design.md)
