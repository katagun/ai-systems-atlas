# ADR 003: Multi-axis directory taxonomy

**Status:** Accepted

## Decision

Each project receives one system family, one compatible primary role, and multiple independent traits for agent relationship, storage architecture, retrieval, capture, lifecycle, deployment, openness, and data ownership. ADR 004 adds family-specific score profiles.

## Consequences

- Vector-based systems are not treated as a peer category to coding agents or PKM applications.
- Cross-category comparisons remain possible without flattening different products.
- Automated classifiers may propose a primary role, but low-confidence discoveries remain candidates.
