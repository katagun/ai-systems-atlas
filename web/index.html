A multi-axis model

One family. One primary role. Several orthogonal traits.

A system can be a coding agent that runs locally, edits files, invokes MCP tools, and keeps session state. Those are different facts—not competing labels or a memory-system score.

External agent memory

A separate library or service persists memory outside the agent runtime. Agents call it through an SDK, API, CLI, or protocol. Replacing the agent does not delete the memory. This improves reuse, but can create an opaque second source of truth.

Ambient capture

Passive collection of digital activity—screenshots, audio, active apps, window titles, or events—without deliberate note taking. It minimizes capture friction but creates severe privacy, noise, retention, and consent obligations.

Agent-system score

Rates reliability, tool use, autonomy, human control, observability and recovery, data sovereignty, interoperability, and maturity. It is not comparable to the memory-system score.

Vector-based

Not a product category. It means embeddings are stored and searched by semantic similarity. PKM tools, RAG apps, memory services, and agents can all use vectors while remaining fundamentally different products.
