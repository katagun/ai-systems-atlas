GenieX

On-device inference runtime for Qualcomm Snapdragon that pulls, caches, and runs language and vision-language models on the Hexagon NPU, Adreno GPU, or CPU, dispatching either to llama.cpp with Qualcomm's Hexagon backend or to the Qualcomm AI Engine Direct runtime, through a CLI, an OpenAI-compatible local server, and Python, Android, and C SDKs.

Boundary
Represents the GenieX software runtime, not the Snapdragon silicon it targets and not Qualcomm AI Hub, the hosted model-compilation and device service from which pre-compiled bundles are fetched. The project was formerly published as NexaAI/nexa-sdk; that repository now redirects to qualcomm/GenieX, and the reviewed product name and owner are GenieX and Qualcomm, described in its own documentation as the community version of Qualcomm GENIE. It is not llama.cpp, which it vendors as a submodule and dispatches to, and not Qualcomm AI Engine Direct, the proprietary Qualcomm runtime reached through a separate plugin repository. Because the product exists to run models on the user's own device and its chat session and local server are how that capability is exercised, it classifies as a runtime rather than an assistant under ADR 015.
