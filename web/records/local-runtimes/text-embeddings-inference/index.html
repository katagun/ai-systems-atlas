Boundary
Represents the self-hosted Text Embeddings Inference server. Hugging Face Inference Endpoints, which can deploy this server on Hugging Face's managed infrastructure, is a separate service boundary. Text Generation Inference is Hugging Face's sibling runtime for causal language-model generation; its repository is archived and excluded from this collection, and this record does not stand in for it, since embedding, classification, and reranking are a distinct workload from generation.
