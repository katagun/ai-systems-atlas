Boundary
Represents the TensorRT LLM library and its trtllm-serve, trtllm-bench, and trtllm-eval tools, operated on GPUs the user controls. It is not TensorRT, the general-purpose NVIDIA deep-learning inference library and engine-builder it can compile through, and it is not NVIDIA's managed offerings, which hold their own serving contract and belong to the inference-service collection. NVIDIA Dynamo and Triton Inference Server orchestrate this engine and are separate boundaries, as is NVIDIA Model Optimizer, the offline quantization toolkit whose checkpoints this runtime loads.
