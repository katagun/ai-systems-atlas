PrivateGPT

The reference answer to the question a private deployment actually asks, which is not which model to run but what to put in front of it: one API surface that keeps a laptop and a datacentre on the same client code, with the data never leaving the operator's hardware.

Product boundary
The record covers PrivateGPT 1.0, "rebuilt from the ground up as a proper API layer for private AI applications". The 2023 proof of concept that gave the repository its following was a local chat-with-your-documents script, which is a different product and is not this record; the bundled /ui workbench ships with the release and is described by the maintainers as "a demonstrator, not the core product". The vendor's commercial Zylon platform is built on this code and is not reviewed here.
