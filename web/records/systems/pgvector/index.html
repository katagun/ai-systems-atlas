pgvector

The retrieval substrate most RAG systems in production actually sit on, published as infrastructure so the choice of vector store is visible without being mistaken for a product category, and as the counter-example to a dedicated vector database: the same retrieval inside the database the rest of the data is already in.

Product boundary
A PostgreSQL extension, not a server or a service. Every query runs inside a PostgreSQL database the operator runs, and the embedding pipeline, chunking, and record identity around the vectors stay with the application. Managed availability comes from hosted PostgreSQL providers that ship the extension, not from a pgvector-operated service.
