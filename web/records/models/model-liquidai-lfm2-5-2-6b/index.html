This record represents the LiquidAI/LFM2.5-2.6B weight release announced 4 August 2026, the 2.6B dense text-to-text checkpoint of the LFM2.5 line. The LFM2.5-2.6B-Base pre-trained checkpoint, the deprecated LFM2-2.6B and LFM2-2.6B-Exp predecessors, the sibling LFM2.5 sizes and the LFM2.5-VL, LFM2.5-Audio, and Liquid Nanos families, the official GGUF, MLX, and ONNX format exports, the LFM2.5-2.6B-DSpark speculative-decoding drafter, the Liquid Playground and the partner API programme, and OpenRouter's hosted route for the same weights are separate boundaries.
