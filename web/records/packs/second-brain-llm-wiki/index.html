Four skill directories under skills/, each holding one SKILL.md: second-brain (an onboarding wizard), second-brain-ingest, second-brain-query, and second-brain-lint. The onboarding skill also bundles six reference documents under skills/second-brain/references/ (agent-config templates for Claude Code, Codex, Cursor, and Gemini CLI, a tooling guide, and the wiki schema) and one script, scripts/onboarding.sh, with a shell test beside it under tests/. The README installs the whole pack with npx skills add NicholasSpisak/second-brain and names Claude Code, Codex, Cursor, and Gemini CLI as hosts, which are the four the agent-config templates cover; it also says 40+ other Agent Skills hosts work, which is a format compatibility list rather than a documented install and is not recorded. Two further documents, docs/llm-wiki.md and docs/REQUIREMENTS.md, describe the pattern and are not installed into a host.
