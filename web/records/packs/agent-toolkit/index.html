Installs
A Claude Code marketplace manifest at .claude-plugin/marketplace.json, registered with /plugin marketplace add and then installed entry by entry with /plugin install <name>@agent-toolkit; each entry names a source directory under dist/plugins/, which scripts/build_plugins.py generates from the repository's skills/, agents/, and commands/ trees. The README also documents npx skills add softaworks/agent-toolkit for Agent Skills hosts and cp -r skills/<name> ~/.claude/skills/ by hand. This record pins the manifest and does not list, count, or review its entries.
