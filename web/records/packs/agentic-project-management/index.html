Per host, apm init unpacks that host's release bundle into the workspace: nine numbered command documents (apm-1-initiate-planner to apm-9-recover), six procedure guides, one subagent definition (apm-archive-explorer), one SKILL.md skill directory (apm-communication, with a bus-integration guide) and the project artifact templates (spec, plan, tracker and a memory index) from the templates/ tree, which holds 27 files in all. The build configuration targets six hosts, GitHub Copilot, Claude Code, Antigravity, Cursor, OpenCode and Codex, placing commands, skills, guides and agents under each host's own directory (for Claude Code, .claude/commands, .claude/skills, .claude/apm-guides and .claude/agents). Antigravity is not a value in the pack_hosts group, so it is not recorded. Two standalone skills, apm-assist and apm-customization, sit under skills/ and are installed by a separate procedure in skills/README.md.
