A vault-template/ directory copied into a vault location: 13 SKILL.md skill directories, 4 agent definitions, 4 rule documents, and 1 output style under vault-template/.claude/, a plugin manifest at vault-template/.claude-plugin/plugin.json declaring commands, agents, skills, hooks, output styles, and rules, and a vault-template/.claude/settings.json carrying 19 permission allow rules and 3 deny rules, 7 environment variables, and three hook configurations (SessionStart, UserPromptSubmit, and a PostToolUse matcher on Write and Edit). The vault content is a root CLAUDE.md with a CLAUDE.local.md.template, 4 Goals documents, 3 note Templates, an example daily note, and an example project with its own CLAUDE.md. Claude Code reads the .claude/ tree from the vault root; Obsidian opens the same directory as a vault. github-actions/claude.yml is offered separately for a vault kept on GitHub.
